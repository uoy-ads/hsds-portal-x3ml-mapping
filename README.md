# hsds-portal-x3ml-mapping
Public repository to share X3ML mapping files (.x3ml only) for HSDS portal data ingestion for AO CAT X3M Mapper tool, which automatically updates the mappings from this repository

## Instructions
- Check the names of the mapping files you have and in this repository. All names should be unique.
- Commit your X3ML mapping files
- Do NOT duplicate nor create a new version of the same mapping. Only one (correct/latest) mapping per collection should exist. Please overwrite the old one, if needed. If you need to use a version control, create a new GitHub repository for your purpose.
- To use them for the AO CAT X3ML mapping tool, no need to export/download them
